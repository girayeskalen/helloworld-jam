# Codex çalışma kuralları

- İşe başlamadan ilgili mevcut dosyaları, `README.md`, `STATUS.md` ve `git status` çıktısını incele; proje yapısına uygun değişiklik yap.
- Ekip arkadaşının ve kullanıcının mevcut değişikliklerini koru. Görev dışındaki değişiklikleri silme, geri alma veya kendi commitine katma; aynı dosyada çakışan işler varsa durumu açıkla.
- Yalnızca istenen görev kapsamında çalış. Oyun motoru henüz seçilmedi; çalıştırma komutları veya oyun kodu uydurma.
- Değişikliğe uygun kontrolleri yap. Dokümantasyonda içerik, bağlantılar ve Git diffini; kodda projede mevcut olan ilgili test veya derleme kontrollerini incele. Yapılamayan kontrolleri nedenleriyle belirt.
- Tamamlandığında neyi değiştirdiğini, hangi kontrolleri yaptığını ve kalan sorunları anlaşılır Türkçeyle açıkla. Görev durumunu gerektiğinde `STATUS.md` içinde güncelle.
- Commit veya push işlemini yalnızca kullanıcı istediğinde yap. Force push kullanma; kullanıcı açıkça istemedikçe değişiklik kaybettiren Git komutları çalıştırma.
